Interactive finance tool, HTML and JavaScript

Estimates a company's intrinsic value per share with a five-year discounted cash flow model and a Gordon Growth terminal value. Change any input and the valuation updates instantly. Dollar figures are in millions, except per-share values.

How it works

  • Free cash flow grows at the chosen rate for five years, and each year is discounted at the WACC.
  • Terminal value = FCF in year 5 × (1 + terminal growth) ÷ (WACC − terminal growth), discounted back five years.
  • Enterprise value = sum of discounted cash flows + discounted terminal value. Equity value = enterprise value − net debt.
